In compiler design, there exists the concept of “bootstrapping”. This refers to compiling a programming language using that language itself.   
  
For example, say I wanted to make a new programming language, the “James” Language. The syntax doesn’t matter, but imagine there are no compilers for this language yet. Maybe a bit of code looks as follows:  
  
Add(3, 10)  
=> 13  
  
How can I make a compiler for this language? How can I convert that snippet of code [Add(3,10)] into an instruction the computer can comprehend? First, I must build a compiler: a program designed to convert that bit of code into something the computer natively understands, e.g., binary. Now, I usually wouldn’t go straight to binary - I might use an intermediary step like compiling to assembly, and then having an assembler convert that to binary. For arguments sake, let’s say I write a compiler that compiles “James” Language down to binary.  
  
What do I write that compiler in? Well, why not write it in “James” Language? In theory, I can’t. No machine can read James Language yet, because there is no compiler for it to translate my code into binary. Rats, my plan is foiled.. right?  
  
Wrong! If I jump to a different language to make a small compiler that JUST compiles what I need to compile my James Language compiler, then I can use James Language to compile my James Language compiler. Seems rather simple, no?  
  
If it doesn’t, I agree. I have not built a bootstrap compiler myself, but it always seemed tedious and more complex than necessary. You can imagine this is somewhat how I feel about teaching English in English. For many of the older children, this poses no problem, as their English is strong enough that I can get the bulk of my point across in English, then fill in the gaps with context or pictures. For younger children, classrooms full of students who don’t know the difference between a lowercase b and d, or a lowercase p and q, I find that I must teach in Nepali to be understood. This is miraculous, because it is very hard to understand me when I am speaking Nepali.
